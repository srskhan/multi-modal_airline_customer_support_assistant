# Multi-Modal Airline Customer Support Assistant

An AI-powered airline customer support assistant that can understand user queries and provide relevant responses using text and voice-based interaction.

## Features

- Airline customer support through natural language queries
- Multi-modal interaction with text and voice
- Flight and ticket price-related information retrieval
- AI-generated customer responses
- SQLite database integration for storing airline price data

## Technologies

- Python
- Large Language Models (LLMs)
- Speech-to-Text / Text-to-Speech
- SQLite
- Jupyter Notebook

## Project Structure

- `Airline Cutomer support assistant.ipynb` – Main implementation
- `prices.db` – Airline pricing database
- `response.wav` – Sample voice response
